# Данные проекта

Исходный набор Central Asia Landslide Inventory не включается в репозиторий.

Причины:

- данные принадлежат внешнему источнику;
- официальный источник уже обеспечивает публичный доступ;
- для проекта достаточно хранить производные результаты и документацию воспроизводимости.

Официальный источник:

https://datacatalog.worldbank.org/search/dataset/0064180/central-asia-landslide-inventory

Для локального воспроизведения необходимо скачать shapefile из официального источника и поместить связанные файлы `Landslides_Inventory.*` в рабочую директорию Google Colab.

Подробное описание источников приведено в `docs/DATA_SOURCES.md`.
