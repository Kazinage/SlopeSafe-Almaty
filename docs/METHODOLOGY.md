# Методика SlopeSafe Almaty

## 1. Постановка задачи

Цель проекта - преобразовать пространственное распределение зарегистрированных оползней в интерпретируемую карту относительной пространственной подверженности и выделить конкретные приоритетные зоны дальнейшего обследования.

Проект не решает задачу прогноза точного времени будущего оползня. Рассчитывается пространственный индекс, основанный на исторической концентрации известных объектов.

## 2. Подготовка данных

Исходный shapefile Central Asia Landslide Inventory имел агрегированную структуру: небольшое число записей атрибутивной таблицы содержало большое количество polygon parts. Геометрия была разобрана на отдельные внешние контуры, после чего для локального анализа использовались репрезентативные точки объектов.

Для дальнейшего расчета расстояний использовалась метрическая система координат EPSG:32643.

В локальной рабочей выборке было использовано 175 объектов.

## 3. Ядерная оценка плотности

Пространственная поверхность рассчитывалась методом Gaussian Kernel Density Estimation:

```text
D(x, y) = Σ exp(-d_i² / 2h²)
```

где:

- `D(x, y)` - относительная пространственная плотность;
- `d_i` - расстояние от точки расчета до i-го зарегистрированного объекта;
- `h` - ширина ядра KDE.

Каждый объект использовался с одинаковым весом `w = 1`.

## 4. Подбор пространственного масштаба

Были проверены значения ширины ядра:

```text
0.5, 1.0, 1.5, 2.0, 3.0, 4.0, 5.0, 7.0, 10.0 км
```

Для каждого варианта выполнялась повторная проверка 80/20. В каждом повторении 80% объектов использовались для построения KDE, а оставшиеся 20% скрывались от модели.

Итоговый выбор выполнялся по способности модели концентрировать скрытые объекты в наиболее высоко оцененной части территории.

Лучшим был выбран пространственный масштаб:

**h = 4.0 км**.

## 5. SlopeSafe Index

Финальная KDE-поверхность преобразуется в процентильный индекс SSI от 0 до 100.

Интерпретация:

- 80-100 - очень высокая;
- 60-80 - высокая;
- 40-60 - средняя;
- 20-40 - низкая;
- 0-20 - очень низкая.

Поскольку используется процентильная нормировка, каждый диапазон занимает примерно 20% площади исследуемой территории.

## 6. Проверка модели

Проверка выполнялась в 15 повторениях случайного разделения 80/20.

Получены следующие средние результаты:

| Доля наиболее высоко оцененной территории | Доля скрытых объектов внутри нее |
|---|---:|
| Top-10% | 75.6% |
| Top-20% | 93.5% |
| Top-30% | 95.8% |
| Top-40% | 97.9% |

Дополнительно рассчитан lift:

```text
Lift = доля скрытых объектов / доля площади
```

Результаты:

- Lift@20% = 4.68;
- Lift@30% = 3.19;
- Lift@40% = 2.45.

Таким образом, Top-20% территории содержат скрытые объекты примерно в 4.68 раза чаще, чем ожидалось бы при равномерном случайном пространственном распределении.

## 7. Приоритетные целевые зоны

Для перехода от широкой зоны высокой подверженности к конкретным участкам был введен дополнительный этап приоритизации.

Кандидаты выбираются в верхней части SSI-поверхности. Для каждого кандидата рассчитываются:

- SSI в центре;
- средний SSI в радиусе 2 км;
- количество известных объектов в радиусе 3 км.

Итоговый Target Priority Score:

```text
Score = 0.55 × SSI_center
      + 0.30 × SSI_local_mean
      + 0.15 × KnownDensityScore
```

После ранжирования используется пространственное разнесение целей, чтобы соседние ячейки одного hotspot не занимали весь список.

Результат делится на три группы:

- T01-T10 - критический приоритет;
- T11-T30 - очень высокий приоритет;
- T31-T50 - расширенный приоритет.

## 8. Практическая интерпретация

Платформа поддерживает три уровня пространственного анализа:

1. Полная поверхность SlopeSafe Index.
2. Критическое ядро Top-10% и Top-20% приоритетной территории.
3. Конкретные целевые зоны T01-T50.

Это позволяет использовать результат как предварительную систему выбора участков для более детального инженерно-геологического, геофизического или полевого обследования.

## 9. Ограничения

Метод основан на историческом пространственном распределении зарегистрированных объектов и не учитывает непосредственно физические факторы склоновой устойчивости, такие как литология, уклон, осадки, подземные воды и сейсмическое воздействие.

Поэтому SlopeSafe Almaty следует интерпретировать как исследовательский и образовательный прототип пространственной приоритизации, а не как официальную карту инженерно-геологической опасности.
