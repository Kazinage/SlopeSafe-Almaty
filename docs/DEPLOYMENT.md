# Публикация SlopeSafe Almaty через GitHub Pages

После того как финальный `index.html` и связанные файлы находятся в корне ветки `main`, публикация выполняется без сервера и backend.

## Шаг 1. Открыть настройки репозитория

Перейдите в:

`Settings -> Pages`

## Шаг 2. Выбрать источник

В разделе **Build and deployment** установите:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

Нажмите **Save**.

## Шаг 3. Дождаться публикации

GitHub Pages обычно публикует статический сайт автоматически. После завершения будет доступен адрес:

https://kazinage.github.io/SlopeSafe-Almaty/

## Шаг 4. Проверка

После публикации рекомендуется проверить:

1. открывается ли WebGIS;
2. загружается ли OpenStreetMap;
3. переключается ли спутниковая карта;
4. отображается ли критическое ядро;
5. работают ли кнопки Top-10, Top-30 и Top-50;
6. работает ли кнопка проверки модели;
7. открывается ли окно методики;
8. работают ли ссылки скачивания CSV и GeoJSON;
9. корректно ли отображается сайт в полноэкранном режиме.

## Обновление сайта

GitHub Pages будет автоматически обновлять опубликованную версию после последующих изменений файлов ветки `main`.

## Важно

Для работы WebGIS не требуется Python-сервер. Финальный сайт представляет собой статический HTML/JavaScript-проект на Leaflet/Folium и может размещаться непосредственно через GitHub Pages.
