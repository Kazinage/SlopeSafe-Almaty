# Google Colab

Вычислительная часть SlopeSafe Almaty была разработана как последовательный воспроизводимый pipeline в Google Colab.

Основные этапы:

1. диагностика исходного shapefile;
2. восстановление отдельных полигональных компонентов;
3. выделение локальной территории исследования;
4. построение KDE;
5. подбор bandwidth;
6. повторная проверка 80/20;
7. расчет SlopeSafe Index;
8. выделение приоритетных целей;
9. генерация финальной Folium/Leaflet WebGIS.

Финальный notebook может быть добавлен в эту папку как `SlopeSafe_Almaty.ipynb` для полного воспроизведения расчетов.
