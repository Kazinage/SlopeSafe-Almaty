Математическая идея

Каждый зарегистрированный объект создает пространственное влияние, которое постепенно уменьшается с расстоянием. Влияния соседних объектов суммируются.

D(x,y) = Σ exp(-d² / 2h²)

Были проверены разные значения пространственного масштаба модели. Лучший результат был получен при h = 4.0 км .

Проверка модели

В каждом эксперименте 80% зарегистрированных объектов использовались для построения модели, а 20% временно скрывались.

Только 20% территории с наиболее высоким индексом содержат в среднем 93.5% скрытых объектов.

Концентрация объектов в этой территории примерно 4.68 раза выше случайного пространственного распределения.

Приоритетные целевые зоны

Общая карта показывает широкие области повышенной пространственной подверженности. Для практического использования внутри наиболее высоких значений индекса дополнительно выделяются компактные пространственно разнесенные участки.

Основной режим платформы показывает ТОП-30 целей. ТОП-10 используется для наиболее приоритетных участков, а ТОП-50 представляет расширенный список.

SlopeSafe Almaty не прогнозирует точное место и время будущего оползня. Платформа предназначена для предварительной пространственной приоритизации территорий дальнейшего детального обследования.
